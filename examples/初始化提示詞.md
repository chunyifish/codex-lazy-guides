# 初始化提示詞範例

## 使用獨立懶人包

```text
請讀這份懶人包，幫我初始化一個可接續的 Codex 專案工作區。先問我必要資訊，提出規劃，等我確認後再建立檔案。
```

## 搭配既有模板

```text
請讀這份懶人包，並可選擇使用 https://github.com/chunyifish/codex-project-template 作為專案骨架。先問我必要資訊，提出規劃，等我確認後再建立檔案。
```

## 開工

```text
開工。請先讀專案中的 README、AGENTS、PROGRESS、TODO、DECISIONS、DEPLOYMENT，整理目前狀態，先不要改檔。
```

## 收工

```text
收工。請整理本次完成內容，更新進度、待辦、決策與部署紀錄，最後檢查 Git 狀態並回報。
```
