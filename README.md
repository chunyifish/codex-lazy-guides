# Codex 懶人包

這個 repo 收錄可直接交給 Codex 使用的工作流程懶人包。

每份懶人包都以「使用者能直接貼給 Codex 執行」為目標，不只是概念說明。內容會包含用途、先備條件、階段式 SOP、常用提示詞、FAQ、安全注意事項與完成判準。

- [Codex 懶人包 #00：Windows 環境建置](00-Windows環境建置.md)
- [Codex 懶人包 #01：初始化可接續專案工作區](01-初始化可接續專案工作區.md)
- [Codex 懶人包 #02：連接 Google NotebookLM](02-Codex連接NotebookLM.md)
- [Codex 懶人包 #03：連接 GitHub](03-Codex連接GitHub.md)
- [Codex 懶人包 #04：連接 Firebase Firestore](04-Codex連接Firebase-Firestore.md)

## 使用方式

1. 打開想使用的懶人包。
2. 把整份 Markdown 交給 Codex。
3. 依照 Codex 的提問補充必要資訊。
4. 等 Codex 提出規劃後，再確認是否執行。

## 適合用途

- 初始化新專案。
- 建立可跨對話接續的工作區。
- 把教學、工具、網頁或自動化流程整理成可維護專案。
- 建立 GitHub、部署與進度追蹤習慣。
